## 7. 回滚

**2026-11-15 修正**：原来这里写的 `.tmp/artifacts/apk/builds/<old>.apk` 对 11-14/15 的构建**不存在**。现在可用的归档是 `dist/save/b1c98f7.apk`（= b1c）。完整步骤（含哈希校验、重启、重新应用壁纸、基线核对）见 `05-*` §9，这里只给最短路径：

```bash
ADB="$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe"
D=9eb96e8a

# 1) 校验存档（必须等于 b1c98f74…）
sha256sum dist/save/b1c98f7.apk

# 2) 装回 b1c，重启
"$ADB" -s $D install -r dist/save/b1c98f7.apk
"$ADB" -s $D reboot
"$ADB" -s $D wait-for-device

# 3) 重启后重新应用项目壁纸（先解锁）
APK_PATH=$("$ADB" -s $D shell pm path org.aliveclean | sed 's/package://' | tr -d '\r')
"$ADB" -s $D shell su 1000 -c \
  "CLASSPATH='$APK_PATH' /system/bin/app_process /system/bin org.aliveclean.SceneApply"

# 4) 恢复 AOD 用户设置（只有确认 full_screen_aod_on 被写坏时才做，并记入本文件）
"$ADB" -s $D shell settings get secure doze_always_on
"$ADB" -s $D shell settings get secure full_screen_aod_on
"$ADB" -s $D shell settings put secure doze_always_on 1     # 仅在原值为 1 时
```

源码回滚：`git switch -c restore-b1c b1c-20261115`（tag → commit `87f1613`），不要 `reset --hard`。
