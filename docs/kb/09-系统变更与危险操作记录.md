| 绿 | 读日志/截图/`settings get`/`dumpsys` | 可做 |

## 4. 未执行/禁止的操作

以下**没有执行**，未来也不默认执行：

- `setprop` 修改任何系统属性；
- 删除 `/data/system`、`/data/data` 下系统数据；
- 修改 SELinux/`permissions.xml`；
- 卸载/禁用系统应用；
- 刷机/格式化；
- 永久改 `settings` 后不恢复；
- 在高频 hook 中写文件/发广播。

如未来必须做，先在本文件新增“待批准”条目，写清：

```text
操作：
原因：
影响：
原值：
恢复：
用户批准：是/否
```

```bash
ADB="$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe"
D=9eb96e8a
"$ADB" -s $D shell settings get secure doze_always_on
"$ADB" -s $D shell settings get secure full_screen_aod_on
"$ADB" -s $D shell dumpsys wallpaper | head -20
```

## 7. 回滚

```bash
# 回到上一个 APK
"$ADB" -s $D install -r .tmp/artifacts/apk/builds/<old>.apk
"$ADB" -s $D reboot

# 恢复 AOD 用户设置
"$ADB" -s $D shell settings put secure doze_always_on 1
"$ADB" -s $D shell su 1000 -c \
  "CLASSPATH=$APK_PATH /system/bin/app_process /system/bin org.aliveclean.SceneApply"
```
