# 0.1.0

第一个公开的 HyperOS 移植版。基于上游 OpenAlive，把「息屏—锁屏—桌面」的连贯过渡接到澎湃系统上。

## 有什么

- 六款息屏壁纸：启航、留光、星月、轻启、山脉、银河；留光带相框、取景框、角度调整。
- 自选照片：裁切、双指缩放、拖动、复位。
- 息屏显示时间、日期、农历。
- 动态壁纸来源：魅族通知光效与光晕、vivo 液态/趣味光栅/闪卡、小米月球雪山几何土星环地球火星。
- 锁屏景深主体在应用本模块壁纸后自动让位，换回原生壁纸即恢复。

## 注意

- 只在 25102RKBEC / HyperOS 4.0.0.33.XPMCNXM / Android 17 上验证过。
- 作用域要勾系统框架、系统界面、主题壁纸三项，少一个动画就接不上。
- 全屏息屏依赖系统 FsAod 开关。
