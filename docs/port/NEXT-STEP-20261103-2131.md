# 补充进展（2026-11-03 21:35，第二轮调研后）

## 已读到的关键实现细节（可直接照着写）

1. `PersonalizeActivity.java` 第 237 行：
   `this.l = LayoutInflater.from(this).inflate(R.layout.personalize_header_view, (ViewGroup) findViewById(R.id.root_container), false);`
   —— 字段 `this.l` 就是 `mHeaderView`；`activity_personalize.xml` 只是 FrameLayout#root_container + 一个 ViewStub。
2. 行初始化方法真名是 `h7am()`（不是 initItemView）；每行都走
   `v0af(int id, int drawable, int string, boolean visible)`（行 672 起）：
   `findViewById(id)` → `setIcon(AppCompatResources.toq(this, drawable))` → `getTitleView().setText(string)` → `setOnClickListener(this)`；`visible=false` 时该行 `setVisibility(8)`。
   也就是说：原生行的图标/标题/点击全部是**运行期逐个 set 上去的**，XML 里的行只是个空壳。
3. 两个行布局**不一样**，不能混用：
   - `miuix_preference_main_layout.xml`（本页实际用）：background=`@drawable/miuix_main_preference_item_background`，图标 style=`@style/Widget.PreferenceIcon.Avator`
   - `miuix_preference_layout.xml`（ThemePreferenceView 无 attrs 时的默认值）：background=`?attr/preferenceItemBackground`，图标 style=`@style/Widget.PreferenceIcon`
   ⇒ 结论：**自己 new ThemePreferenceView(context) 会拿到"小图标版"**。做法：
   `new ThemePreferenceView(context)` → `removeAllViews()` → 再 `inflate(R.layout.miuix_preference_main_layout, row, true)`；
   然后**把 aod_item 的 padding 四个值抄给新行**（`row.setPadding(aod.getPaddingLeft(), ...)`），这样纵向 167px、横向 38px 内缩能对齐。
4. `com.miui.support.cardview.CardView extends androidx.cardview.widget.CardView`，
   构造：`CardView(Context)` → `CardView(Context, AttributeSet)` → `CardView(Context, AttributeSet, R.attr.f55980ki)`；
   `setRadius(float)` 会把背景重新包成 `miuix.smooth.SmoothContainerDrawableForCardView`（平滑圆角）。
   所以造新卡：反射 `new CardView(context)` → `setCardBackgroundColor(anchor.getCardBackgroundColor().getDefaultColor())` → 最后 `setRadius(anchor.getRadius())`（顺序不能反）→ `setCardElevation(0f)`。
5. 模块编译 classpath 里**没有 androidx.constraintlayout**（build_release.py 只挂 xposed + ui-api + ort）。
   ⇒ ConstraintLayout.LayoutParams 必须反射：
   `Class.forName("androidx.constraintlayout.widget.ConstraintLayout$LayoutParams")`，构造 `(int width, int height)`；
   字段 `topToTop/topToBottom/startToStart/endToStart/endToEnd` 都是 public int；`PARENT_ID=0`，`UNSET=-1`。
   **更省事的做法**：把锚点卡（theme_personlize_card_view）现有的 LayoutParams 反射复制一份给新卡（宽高与左右约束照抄），
   只改 `topToBottom = 新卡 id`、`topToTop = -1`；再把锚点卡的 `topToBottom = 新卡 id`、`topMargin = 36px(12dp)`。
6. 模块入口 `CleanHooks.handleLoadPackage` 里，`com.android.thememanager` 分支要加在
   `if (!"android".equals(p.packageName) && !systemUi) return;` **之前**（那行之后只处理 android/systemui）。
7. 模块有 `xposed_scope` 数组资源（AndroidManifest 第 37 行 `<meta-data android:name="xposedscope" android:resource="@array/xposed_scope"/>`）
   —— 需要确认里面含 `com.android.thememanager`，否则 LSPosed 不会把代码注入主题壁纸进程。
